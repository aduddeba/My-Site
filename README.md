# Achyutha Duddebanda Portfolio

A responsive single-page portfolio highlighting my software engineering experience, selected projects, education, and technical skills.

## Run locally

Open `index.html` in a browser. No installation or build step is required.

For a local development server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.

GitHub will display the public portfolio URL after deployment finishes.

## Customize

The page uses plain HTML, CSS, and JavaScript in one file. Edit the content, colors, links, and layout directly in `index.html`.
